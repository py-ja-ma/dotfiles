# campfire

The recorder: a desktop with 32 GB of RAM, an RTX 3060 and a capture card, which records what cabin shows.
Not installed yet (2026-10-13); its host file is `modules/hosts/campfire.nix`.
After the install, `dram harvest` on campfire fills this directory with its package lists, enabled units, `/etc` copies and hardware facts ([hosts/README.md](../README.md)).
