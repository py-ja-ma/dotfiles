# Vault

Plain Markdown in git (docs/toolchain/profiles/office.md in the dotfiles repo). Open the folder in Zettlr; `zk` works in the terminal.

    inbox/      quick capture, sorted weekly
    notes/      permanent notes, one idea each
    projects/   one folder per project (tutorials, homelab, business)
    school/     one folder per course
    journal/    YYYY-MM-DD.md
    attachments/
