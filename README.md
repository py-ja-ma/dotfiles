# dotfiles

Configuration for my computers.
cabin is a desktop that runs Arch Linux, Windows 11 and three test systems, lantern is an Arch laptop, thermos a Windows laptop, and lodge the Mac where I edit and release.
One Nix flake describes the Arch hosts and the Windows PCs: Home Manager owns `~/.config` and my command-line tools, and the rest of an Arch host is package lists and idempotent scripts that `dram apply` converges.
Packages come from per-role lists and a signed pacman repo I build on cabin.
The look is Letterpress: a printed page with one accent color and words in place of icons.
The command that runs all of it is `dram`, a measure of whiskey, after the drink-named themes.

![The rEFInd background from system/refind-letterpress/: dark paper and the pj wordmark in the lower left.](system/refind-letterpress/background.png)

The boot menu's background, drawn by `system/gen-boot-assets.py` from the house palette.

## Take a piece

Most directories stand on their own.
Each one's README says what it needs, how to copy it without the rest of this repo, and its license.
[The catalogue](docs/catalogue.md) lists every one of them, from the fact box at the top of each README.

| Piece | Where | Needs |
|---|---|---|
| Letterpress Waybar masthead | `dotfiles/.config/waybar/` | Waybar, three fonts, a palette file |
| 17 themes and their generators | `dotfiles/.config/themes/`, `bin/gen-*.py` | Python 3 |
| rEFInd and Plymouth themes | `system/refind-letterpress/`, `system/plymouth-letterpress/` | rEFInd, Plymouth |
| Firewall and host hardening | `system/nftables.conf`, `system/harden.sh` | Arch, nftables |
| Secure Boot with your own keys | `system/secureboot-setup.sh`, `system/secureboot-test.sh` | sbctl, systemd-boot |
| Snapshots with boot entries | `system/snapshots-setup.sh`, `system/snapper/` | btrfs, snapper |
| A signed pacman repo | `pkgs/` | devtools, GnuPG |
| A software register and its check | `packages/register.tsv`, `bin/check-register.py` | Python 3 |
| Windows settings from a Nix flake | `windows/` | Nix, winget |
| yazi flavors | `dotfiles/.config/yazi/flavors/` | yazi |

## Running it on my machines

[The handbook](docs/records/handbook/README.md) takes a fresh Arch install to a `dram` host and back out again, one chapter per task, with real output and a "Done when" list.
Three commands to know first: `dram --help`, `dram doctor`, `dram update --check`.
[Operations](docs/operations/README.md) has the everyday commands and the rules that have each cost a machine once.
