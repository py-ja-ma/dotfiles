# Shell & bars

[Design](../README.md) › Shell & bars

The surfaces I work in: the Hyprland session, the bar, the launchers and notes, the terminal and its prompt, and the screens before the desktop.
On the Arch hosts each of them reads the active theme from `~/.config/themes/current`.
On Windows the masthead, the terminal and the prompt follow washi.

## How the branches fit

`modules/desktop.nix` links each configuration into `~/.config`, and `hyprland.lua` starts the session's pieces: Waybar, swaync, swayosd, the wallpaper and the login toast.
Each piece imports its colors from `themes/current`, so `dram theme` restarts or signals it ([Switcher](../themes/switcher.md)).
The bar's layout is written once, in Waybar's own files, and `bin/gen-windows-look.py` turns it into the Zebar masthead, stopping on a module it cannot map.
The boot screens come before any of this and keep the house palette.
The case display is the third status surface beside Waybar and Zebar: it shows the CPU temperature, which the Windows masthead leaves out.
