# Templates

[Office of Records](../README.md) › Templates

The starting point for each kind of page in the chart.
Copy the block from the template, fill the angle brackets, and delete what does not apply.
Where each kind of page lives: [Organization](../../README.md#kinds-of-page).

| Template | For |
|---|---|
| [Directorate](directorate.md) | `docs/<directorate>/README.md`: an index of the divisions and the rules that hold across them |
| [Division](division.md) | `docs/<directorate>/<division>/README.md`: what the division covers and a table of its branches |
| [Branch](branch.md) | `docs/<directorate>/<division>/<branch>.md`: one branch that spans several modules |
| [Module README](module.md) | `README.md` next to the code of a part someone could copy alone |
