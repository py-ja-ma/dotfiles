# Division page

[Office of Records](../README.md) › [Templates](README.md) › Division page

A division page is the `README.md` of its directory, so GitHub shows it under the file list.
It says what the division covers and lists its branches; a branch that is one module has its module README as its page.

````markdown
# <Division>

[<Directorate>](../README.md) › <Division>

<Two or three sentences: what the division is responsible for and on which hosts.>

| Branch | What it does | Code | Copy alone |
|---|---|---|---|
| <Branch> | <one line> | `<path>` | <yes / yes, after one change / no> |

## How the branches fit

<A short explanation or a diagram of how the branches connect.
Link the decision records; don't restate them.>

## Operating it

<Links into the handbook for routine work. No steps here.>

## Status

<One dated line, then open items.>
````
